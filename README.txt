# Reasons I Love You — Best Friends 💗

## تشغيل الموقع
1. فك الضغط عن الملف.
2. افتح `index.html` في المتصفح.

## إضافة الأغنية
ضع ملف الأغنية داخل نفس فولدر الموقع، وغيّر اسمه بالضبط إلى:

`ana-dahrak.mp3`

الموقع مجهز بالفعل لتشغيله من زر الموسيقى.

## النشر على GitHub Pages
ارفع كل الملفات الموجودة داخل هذا الفولدر إلى نفس الـ repository، ثم فعّل GitHub Pages من Settings > Pages.
